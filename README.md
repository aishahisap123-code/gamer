# The Last Circuit

**The Last Circuit** is a pixel-art survival horror and puzzle escape game built entirely from scratch using vanilla HTML5 Canvas, CSS, and JavaScript.

## Overview
Dive into a tense, atmospheric horror escape experience where every dark corridor could be your last. Armed with only a flickering flashlight beam, you must navigate a winding, organic multi-path labyrinth, hunt down missing items hidden in the rubble, and solve environmental puzzles to survive.

## Key Features
* **Organic Labyrinths:** Explore hand-crafted, multi-path room designs packed with tight corners, dead ends, and chilling secrets.
* **Immersive Lighting Engine:** Experience claustrophobic tension with a dynamic, radial flashlight effect that pierces the deep shadows.
* **Interactive Puzzles:** Search the environment to find missing fuses, restore dead power grids at the fuse box, and unlock heavy electric security gates.
* **Nerve-Wracking Surprises:** Stay on edge as random jump scares and atmospheric prompts pull you deeper into the dark.

## How to Play / Run
1. Clone or download this repository to your local machine.
2. Make sure all files (`index.html`, `game.js`, `room1.js`, etc.) are in the root folder.
3. Open `index.html` directly in any modern web browser, or run it locally using **Live Server** in VS Code.
4. Click **Start Game**, use your movement keys to explore the maze, and press **[E]** to interact with objects and fuses!
